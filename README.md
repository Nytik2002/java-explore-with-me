
# java-explore-with-me

Дипломный проект Яндекс Практикума.

Приложение для поиска и создания мероприятий. Пользователи могут публиковать события, просматривать мероприятия и подавать заявки на участие.

## Структура проекта

Проект состоит из двух сервисов:

- `main-service` — основной сервис для работы с пользователями, категориями, событиями, заявками и подборками.
- `stats-service` — сервис для сбора и получения статистики просмотров.

Для хранения данных используется PostgreSQL. Сервисы запускаются через Docker Compose.

## Дополнительная функциональность

На третьем этапе добавил возможность оставлять комментарии к событиям.

Пользователи могут создавать комментарии, просматривать их, редактировать и удалять свои комментарии.

Также добавлены проверки текста и запрет на изменение и удаление чужих комментариев.

## Тестирование

Для проверки комментариев добавил Postman-коллекцию `postman/feature.json`.

В ней находятся тесты создания, получения, редактирования и удаления комментариев, а также проверки кодов ответов при ошибках.
